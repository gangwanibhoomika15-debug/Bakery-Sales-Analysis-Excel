# 📊 Bakery Sales Analysis
Sales analysis and data visualization of bakery items using Microsoft Excel.

## 📌 Project Overview
This project presents an initial exploratory analysis of daily bakery sales data. It demonstrates data structuring, metric calculations using standard Excel formulas, and data visualization.

## 🔑 Key Metrics & Analysis
* **Total Revenue Generated:** ₹88,550.00
* **Average Quantity Sold:** 38.13 units
* **Highest Revenue Item:** Chocolate Cake (₹33,750.00)
* **Lowest Revenue Item:** Veg Sandwich (₹2,250.00)

## 🛠️ Tools & Excel Skills Applied
* **Data Structuring:** Category-wise separation (Bakery, Beverage, Snacks).
* **Excel Formulas Used:** `SUM()`, `AVERAGE()`, `MAX()`, `MIN()`.
* **Data Visualization:** Clustered Column Chart comparing product-wise revenue performance.

## 📊 Key Insights
1. **Top Performer:** Bakery category led the sales, driven heavily by Chocolate Cake demand.
2. **Growth Opportunity:** Beverages (Cold Coffee) and Snacks (Veg Sandwich) contributed lower overall revenue, indicating potential for promotional bundling.
